# Project
**Project Name: Smart Interview Assessment System (Python + MySQL)**

My project is **Smart Interview Assessment System**, which I developed using **Python** and **MySQL**.

The main objective of this project is to automate the interview assessment process. It allows candidates to register, choose a test category such as Python, SQL, or Aptitude, and take an online assessment.

The application retrieves questions from the MySQL database based on the selected category. After the candidate submits the answers, the system automatically evaluates the responses, calculates the score, percentage, and pass/fail status, and stores the results in the database.

The administrator can view all candidate results through the application. I also implemented a **CSV Export** feature, which allows the admin to export candidate results into a CSV file for reporting and analysis. Additionally, I added a basic **timer-based test** feature that limits the time available for answering each question.

For the backend, I used Python concepts such as loops, conditional statements, functions, exception handling, and MySQL database connectivity. For database operations, I used SQL queries like **INSERT**, **SELECT**, and **UPDATE**.

This project helped me strengthen my skills in Python programming, SQL, database management, and application development. It also improved my problem-solving and logical thinking skills.
